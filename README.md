# 🌙 ¿QuiénSigue?

Aplicación web para gestionar turnos nocturnos y días compensatorios del equipo de ingeniería. Construida con **Streamlit** y **Supabase**.

## Funcionalidades

| Sección | Descripción |
|---|---|
| 📊 Dashboard | Saldo neto de compensatorios por ingeniero con métricas visuales |
| 📝 Registrar Turno | Anota quién hizo el control nocturno y en qué fecha |
| ☀️ Solicitar Compensatorio | Descuenta un día del saldo de un ingeniero |
| 📋 Historial | Últimos 10 movimientos registrados |

### Lógica de días
- **Lunes a Viernes** → +1 día compensatorio
- **Sábado o Domingo** → +2 días compensatorios
- **Canje de día** → -1 día del saldo

## Stack

- [Streamlit](https://streamlit.io/) — interfaz web
- [Supabase](https://supabase.com/) — base de datos PostgreSQL
- [st-supabase-connection](https://github.com/SiddhantSadangi/st_supabase_connection) — conector oficial
- [Pandas](https://pandas.pydata.org/) — procesamiento de datos

## Requisitos previos

- Python 3.10+
- Una cuenta y proyecto en [Supabase](https://supabase.com/)

## Instalación

```bash
# 1. Clonar el repositorio
git clone https://github.com/tu-usuario/quien-sigue.git
cd quien-sigue

# 2. Instalar dependencias
pip install -r requirements.txt

# 3. Configurar credenciales (ver sección de configuración)
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# Editar secrets.toml con tus valores reales

# 4. Correr la app
streamlit run app.py
```

## Configuración

Crea el archivo `.streamlit/secrets.toml` con tus credenciales de Supabase:

```toml
[connections.supabase]
SUPABASE_URL = "https://TU_PROJECT_ID.supabase.co"
SUPABASE_KEY = "eyJ..."   # Clave anon/public — Settings → API
```

> **Nunca** subas este archivo al repositorio. Ya está incluido en el `.gitignore`.

### Base de datos

Ejecuta el siguiente SQL en el **SQL Editor** de Supabase para crear la tabla:

```sql
create table controles (
  id           bigint generated by default as identity primary key,
  created_at   timestamptz default now() not null,
  ingeniero    text        not null,
  fecha        date        not null,
  tipo         text        not null,       -- 'Control Nocturno' | 'Canje de Día'
  dias_ganados int4        default 0 not null,
  dias_usados  int4        default 0 not null,
  descripcion  text
);
```
